# Reporte Ejecutivo de Mitigación

## Resumen de Hallazgos

Se realizó un escaneo de red sigiloso en la dirección IP **186.64.114.50**, donde se identificaron tres puertos abiertos y sus respectivos servicios. A continuación, se detalla la evaluación de riesgo y las recomendaciones de mitigación.

### Detalles de los Servicios Identificados

| Puerto | Servicio | Riesgo | Descripción |
|--------|----------|--------|-------------|
| 21     | FTP      | CRÍTICO| El servicio FTP está en texto plano, lo que expone credenciales y datos a interceptaciones. |
| 25     | SMTP     | BAJO   | El servicio SMTP está abierto, pero no presenta vulnerabilidades críticas en esta configuración. |
| 80     | HTTP     | BAJO   | El servicio HTTP está operativo, pero no se detectaron vulnerabilidades inmediatas. |

## Evaluación de Riesgo

1. **FTP (Puerto 21)**: 
   - **Riesgo**: CRÍTICO
   - **Justificación**: El uso de FTP sin cifrado permite que las credenciales y datos sean transmitidos en texto plano, lo que facilita ataques de tipo "man-in-the-middle" y la captura de credenciales.

2. **SMTP (Puerto 25)**:
   - **Riesgo**: BAJO
   - **Justificación**: Aunque el servicio SMTP está expuesto, no se detectaron configuraciones inseguras en esta evaluación. Sin embargo, se recomienda monitorear el tráfico para detectar posibles abusos.

3. **HTTP (Puerto 80)**:
   - **Riesgo**: BAJO
   - **Justificación**: El servicio HTTP está activo, pero no se identificaron vulnerabilidades críticas. Se sugiere considerar la implementación de HTTPS para asegurar la comunicación.

## Recomendaciones de Mitigación

### Para el servicio FTP (Puerto 21):
- **Acción**: Deshabilitar el servicio FTP.
- **Alternativa**: Implementar SFTP o SCP para la transferencia segura de archivos.
- **Configuración**: Asegurarse de que el nuevo servicio esté correctamente configurado para utilizar autenticación fuerte y cifrado.

### Para el servicio SMTP (Puerto 25):
- **Acción**: Monitorear el tráfico SMTP y aplicar filtros para prevenir el envío de spam.
- **Configuración**: Considerar la implementación de autenticación SMTP (SMTP AUTH) y STARTTLS para cifrar las comunicaciones.

### Para el servicio HTTP (Puerto 80):
- **Acción**: Migrar a HTTPS.
- **Configuración**: Obtener un certificado SSL/TLS válido y configurar el servidor web para redirigir automáticamente el tráfico HTTP a HTTPS.

## Conclusión

La evaluación de la red ha revelado la presencia de servicios críticos que requieren atención inmediata, especialmente el servicio FTP. Se recomienda seguir las acciones de mitigación propuestas para reducir el riesgo de exposición y mejorar la seguridad general de la infraestructura.
